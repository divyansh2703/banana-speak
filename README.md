# Banana Speak Text Interaction Prototype

A small browser exercise in event handling and DOM updates. The interface is themed around Banana Speak, but its current click handler adds a fixed string to the input rather than translating text.

## The question

How can a button read a text field and update a page without a reload?

## Tools and methods

HTML, JavaScript, DOM manipulation.

## Work in this repository

1. Selected input, button and output elements through the DOM.
2. Attached a click handler that reads the entered text.
3. Displayed a fixed prefix followed by the input in the output area.

## Getting started

Open `index.html` in a browser. No dependency installation is required for the current local interaction.

## Current limitations

1. There is no translation API call or language model in the committed JavaScript. The repository should be presented as a UI prototype.
